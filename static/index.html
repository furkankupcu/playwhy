Goal Explainer rebuilds where every player stood from a single broadcast camera, reads what the key players were doing, and only says what it can point to in the clip.

How it works
  1. SAM 3.1 tracks the ball, both teams, keepers and referee.
  2. Each frame is mapped from pixels to pitch metres.
  3. Passes, the offside line and the shot are found from positions.
  4. Muse Spark reads body cues of the key players: facing, gaze, raised arm.
  5. Muse Spark writes claims; code drops any claim without evidence.
